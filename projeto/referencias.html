Referências

Ilustrações e identidade visual

Todas as ilustrações do site (logotipo, imagem de capa, artes das categorias e das playlists) são arquivos SVG criados pelo autor do projeto especialmente para o MusicList. Nenhum modelo, tema ou biblioteca de terceiros foi utilizado.

Dados das músicas

Título, artista e ano de lançamento de cada faixa foram conferidos nas páginas públicas das enciclopédias e bases de dados musicais listadas abaixo. As descrições curtas de cada música e de cada playlist são textos autorais, escritos para este projeto.

  • Wikipédia em português — verbetes das músicas, dos artistas e dos álbuns citados.
  • Wikipedia (inglês) — verbetes das faixas internacionais.
  • MusicBrainz — conferência dos anos de lançamento e da grafia dos nomes.
  • Discogs — conferência de créditos e participações nas faixas.

Documentação técnica

  • MDN Web Docs — referência de HTML, CSS e JavaScript usada durante o desenvolvimento.
  • WCAG 2.2 Quick Reference (W3C) — critérios de acessibilidade aplicados ao contraste, aos rótulos e à navegação por teclado.
  • Google Fonts — famílias tipográficas Space Grotesk e Nunito Sans, distribuídas sob licença livre.

Sobre o projeto

MusicList é o projeto final do curso WDD 131 – Fundamentos da Web Dinâmica, da Universidade Brigham Young–Idaho, desenvolvido individualmente por Jean Felipe da Silva. O conteúdo tem finalidade educacional e o site não comercializa nem distribui gravações musicais.
